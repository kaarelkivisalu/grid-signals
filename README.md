# Grid Signals

Nordic-Baltic energy intelligence platform: data pipelines, interactive dashboards, forecasting, and an LLM-powered analysis agent for electricity markets.

**Live demo:** [grid-signals.kaarelkivisalu.ee](https://grid-signals.kaarelkivisalu.ee/)

## What it does

- **Data pipelines.** Ingests day-ahead prices, generation mix, load, cross-border flows, and outages from ENTSO-E, plus weather forecasts from Open-Meteo. Includes backfill, validation, and cron-based scheduling.
- **Interactive dashboard.** Streamlit UI with price charts, generation mix breakdowns, cross-border flow visualization, wind-vs-price correlation, and price heatmaps.
- **LLM agent.** Claude with tool use queries the database through 8 structured tools to answer energy market questions in natural language.
- **Automated briefings.** Daily reports covering price outlook, wind/weather, outages, spreads, and a watch list, generated by the agent.

## Architecture

```
Data Sources           DuckDB             Analysis & Output
─────────────       ────────────       ─────────────────────
ENTSO-E API  ──┐    prices             Streamlit dashboard
Open-Meteo   ──┼──▶ generation    ──▶  LLM agent (Claude)
Cron / CLI   ──┘    load, flows        Forecasting models
                    outages, weather   Automated briefings
```

## Local setup

```bash
git clone <repo-url> && cd grid-signals
uv sync

export ENTSOE_API_KEY="your-key"      # transparency.entsoe.eu
export ANTHROPIC_API_KEY="your-key"

uv run grid-signals daily             # ingest data
uv run grid-signals weather           # weather forecasts
uv run grid-signals backfill          # backfill a date range
uv run grid-signals validate          # data quality checks
uv run grid-signals briefing          # generate daily briefing
uv run grid-signals ui                # launch web UI
```

All commands support `--help` for full usage details.
